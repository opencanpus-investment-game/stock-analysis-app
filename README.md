# 株式分析体験ツール(オープンキャンパス投資ゲーム用)

参加者がスマホで6つの架空銘柄を分析し、その結果をもとに投資ゲームで売買するための分析ツール。
**読み取り専用・ステートレス**(入力・保存機能なし)。投資判断は紙のワークシートに記入する運用。

## 起動方法(ローカル)

```bash
pip install -r requirements.txt
streamlit run app.py
```

スマホでの確認: PCと同じWi-Fiに繋いだスマホで `http://<PCのIPアドレス>:8501` を開く。

## デプロイ(Streamlit Community Cloud / 無料)

1. このリポジトリをGitHubにpush
2. https://share.streamlit.io から New app → リポジトリを選択 → `app.py` を指定
3. 発行されたURLをQRコード化して当日掲示

### 30人同時アクセスの注意
- データ読み込みは `@st.cache_data` で全セッション共有済み(必ず維持すること)
- 本番前にサークル等で10〜15人同時アクセスの負荷テストを実施する
- 万一の障害時は、ローカルPC + 大学Wi-Fiで代替ホスト(上記「起動方法」)

## データの差し替え

`data/prices.csv`(date, name, close のロング形式)と `data/stocks.csv` を置き換えるだけ。
コード修正は不要。銘柄名を変える場合は `app.py` の `STOCK_INFO`(色・説明・ヒント)も更新する。

データの生成・バランス検証スクリプト:
- `generate_analysis_data.py` … 分析用90日データの生成(シード・パラメータ管理)
- `design_cards_and_balance.py` … ゲーム側のカード設計とモンテカルロ検証

## 設計意図(引き継ぎ用)

- 6銘柄にはそれぞれ「分析すると気づける性格」が埋め込まれている(詳細は要件定義書§3)
- 分析データの統計的性格と、ゲーム側(基本利回り+イベントカード)の挙動は整合するよう設計済み
- ゲーム側ルール「1銘柄への投資は50%まで」とセットでバランスが成立している
